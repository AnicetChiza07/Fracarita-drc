# Fracarita RDC - Site Officiel

Site web officiel de l'ONG Fracarita RDC, développé pour connecter les communautés, présenter nos actions humanitaires et gérer les opportunités de bénévolat.

## Fonctionnalités

- **Frontend Premium** : Design épuré, animations fluides, 100% responsive.
- **Blog & Actualités** : Système de gestion d'articles avec éditeur riche (Tiptap).
- **Espace Opportunités** : Offres d'emploi, stages et appels d'offres dynamiques.
- **Rapports Transparents** : Téléchargement de rapports PDF et états financiers.
- **Formulaire de Contact** : Envoi direct vers le tableau de bord administrateur.
- **Admin Dashboard** : Gestion complète du contenu (CRUD) avec authentification JWT.

## 🛠️ Stack Technique

- **Framework** : Next.js 15 (App Router)
- **Langage** : TypeScript (Strict)
- **Base de données** : PostgreSQL avec Prisma ORM
- **Styling** : Tailwind CSS
- **Upload de fichiers** : UploadThing
- **Éditeur de texte** : Tiptap
- **Authentification** : JWT (JSON Web Tokens)
